# Table legends

## Main tables (computed from `results/`)

**Table 1** — Differentially methylated cytosines (DMCs) per contrast (methylKit, q < 0.05). Discovery and systematisation use the same 108-gene panel with uniform ±15 kb windows, differing only in contrast scope; the discovery contrast is the same June Angus-versus-Nellore comparison as systematisation contrast C3.

**Table 2** — High-tier candidate genes (priority score ≥ 5) from the multi-omic bridge on the 108-gene panel, with regulatory methylation (promoter/upstream Δβ), best heat-stress expression, and orthogonal fetal-liver corroboration. Reg. Δβ is the regulatory-window mean; for *ERN1* and *GRHL3* this regulatory direction is hypomethylated although the whole-gene mean is gene-body-hypermethylated.


## Supplementary tables (`tables/`, one file per Online Resource)

Generated by `scripts/python/export_online_resources.py` from `results/` (OR01–OR09); OR10 and OR11 are curated tables.

- **Online Resource 1** — `OR01_bridge_overlap47.tsv`: Bridge gene set: the 47 genes marked at both omic layers, ranked by priority score.

- **Online Resource 2** — `OR02_bridge_gene_table.tsv`: Complete bridge table: every gene evaluated, with in_methylation/in_expression flags.

- **Online Resource 3** — `OR03_concordant_by_contrast.tsv`: Concordant bridge genes by contributing contrast (eleven informative contrasts).

- **Online Resource 4** — `OR04_module_enrichment.tsv`: Functional-module enrichment (hypergeometric; universe = 108-gene panel, n = 19 concordant; no module survives BH).

- **Online Resource 5** — `OR05_fetalliver_C6.tsv`: Fetal-liver WGBS corroboration per bridge candidate (25/47 carry a DMR; 15 same direction).

- **Online Resource 6** — `OR06_cissnp_1000bull.tsv`: cis-genetic classification of the 2719 subspecies DMCs vs 1000 Bull Genomes (CpG-SNP/near-SNP/no-SNP).

- **Online Resource 7** — `OR07_Fst_AIM_context.tsv`: Gyr-vs-Holstein Fst/ancestry-informative-marker status of the 47 candidates (1000 Bull Genomes; Section 2.12): triple-convergence (Fst>=0.30): ABCG2, CYP11A1, GH1, OAS1Z, RPL19, RSAD2; all ten high-tier candidates are epi-dominant.

- **Online Resource 8** — `OR08_matched_atlas_Zhou.tsv`: Matched-sample promoter-methylation vs expression Spearman correlations (Zhou et al. 2020 atlas; 88 genes).

- **Online Resource 9** — `OR09_motifbreakR.tsv`: Subspecies DMCs co-localized with motif-disrupting SNPs for SP1/KLF4 (80 DMCs; motifbreakR, Section 2.12).

- **Online Resource 10** — `OR10_panel108_curated.tsv`: The 108-gene candidate panel: functional module, basis for inclusion, and a supporting reference (DOI/PMID) per gene.

- **Online Resource 11** — `OR11_motif_enrichment.tsv`: Transcription-factor motif enrichment at discovery DMC flanks: all 43 motifs tested, with fold enrichment, sequence counts and nominal/BH p-values; six motifs (KLF4, NF-kB p65, NFAT1, NF-kB p50, HSF1, SP1) survive q<0.05 with multi-sequence support (IRF3 reaches q=0.047 on a single sequence and is not robust).


The column `high_tier` (Online Resources 6, 8, 9) flags the ten high-tier candidates of Table 2.
